Projeto de Engenharia de Dados: Pipeline de CRM no Databricks

Tecnologias e Ferramentas Utilizadas Apache Spark(PySpark), Spark SQL, Python Ambiente, Databricks

  • Desenvolvimento de um fluxo ETL completo utilizando a API nativa do PySpark dentro do ecossistema Databricks.
  • Manipulação avançada de DataFrames: filtragem de registros, agregações de métricas e tratamento de valores nulos.
  • Carga e estruturação de dados otimizada, utilizando particionamento de diretórios e salvamento no formato JSON para consumo analítico.
