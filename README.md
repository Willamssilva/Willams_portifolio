Bem-vindo ao repositório do meu portfólio digital! Este espaço foi desenvolvido para apresentar minha trajetória profissional, minhas habilidades técnicas e os projetos práticos que venho desenvolvendo na área de tecnologia.

Sou um Desenvolvedor formado em Análise e Desenvolvimento de Sistemas. Tenho uma base sólida na construção de interfaces e lógicas Web, e atualmente meu foco de desenvolvimento e estudos práticos está voltado para o ecossistema de **Engenharia e Análise de Dados**.

---

## 🎯 Objetivo do Projeto

Servir como um hub central ("vitrine") para centralizar meus projetos, facilitando o acesso de recrutadores, líderes técnicos e outros desenvolvedores aos códigos que escrevo e às soluções que construo, abrangendo desde o Front-End até pipelines de processamento de dados.

## 🚀 Tecnologias Utilizadas na Construção

Este portfólio foi desenvolvido do zero, priorizando código limpo, semântica e responsividade, utilizando:

* **HTML5** (Estruturação semântica e acessibilidade)
* **CSS3** (Estilização avançada, Flexbox, CSS Grid e media queries para responsividade)
* **JavaScript (ES6+)** (Interatividade e manipulação do DOM)
* **Git & GitHub** (Versionamento de código e hospedagem via GitHub Pages)
